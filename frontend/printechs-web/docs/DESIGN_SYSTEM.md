# Design System

## Direction

Premium B2B industrial / retail / software technology brand for Saudi Arabia.

Visual cues:

- Deep ink surfaces
- Clean paper / white sections
- Soft mist alternating bands
- Teal signal accent
- Strong display typography
- Editorial spacing
- Minimal card chrome

## Tokens

| Token | Value | Use |
|-------|-------|-----|
| ink | `#0b1220` | Primary text / dark surfaces |
| steel | `#162033` | Secondary dark panels |
| paper | `#f7f8fa` | Soft page background |
| white | `#ffffff` | Bright sections |
| mist | `#eef1f5` | Alternate section background |
| slate | `#5a6472` | Secondary text |
| signal | `#14b8a6` | Accent / focus / CTA |

## Typography

- Display: Sora
- Body: Source Sans 3
- Hero: large, balanced wrapping
- Section titles: clear H2 hierarchy
- Eyebrows: small, tracked, restrained

## Spacing

- Content max width: `72rem` (`max-w-content`)
- Section vertical rhythm: `clamp(4rem, 7vw, 7rem)`
- Page gutters: `clamp(1.25rem, 3vw, 2rem)`

## Components

- Container, Section, Heading, Button, Badge, Card, CTA
- FeatureGrid, LogoGrid, Breadcrumb, PageIntro
- PosterVideo (poster-first media)

## Motion

- Fade-up on hero
- Slow hero media pan (respects reduced motion)
- Image zoom on hover
- Subtle card lift
- No bounce / scroll hijacking
